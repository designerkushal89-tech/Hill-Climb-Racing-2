# Hill Rivals Game UI Concept

This workspace contains the Hill Rivals game UI concept: an HTML wireframe and playable-style prototype, a screen-flow outline, garage and race scene images, a UI preview, and the editable FigCraft design source. The `.figcraft` file is a native, editable design file.

## Open locally

Open `Hill-Climb-Racing-2-Game-Wireframe.html` or `Hill-Climb-Racing-2-Prototype.html` in a modern web browser (for example, double-click the file or drag it into a browser window). No server or installation is required.
